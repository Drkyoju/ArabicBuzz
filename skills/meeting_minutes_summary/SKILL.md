# ملخص الاجتماعات

عند طلب محضر أو ملخص اجتماع من ملاحظات/نص:

أخرج دائماً أربعة أقسام بالعربية الفصحى المهنية:
1. **الملخص التنفيذي** (3–5 أسطر)
2. **القرارات** — فقط ما ذُكر صراحة
3. **المهام** — المسؤول · الموعد إن وُجد
4. **البنود المفتوحة**

قواعد:
- لا تخترع حضوراً أو قرارات غير مذكورة.
- إن نقصت معلومة اذكرها تحت «نواقص» بدل الافتراض.
- للوقفات اليومية يمكن استخدام قالب مختصر: أمس / اليوم / العوائق.
