# متابعة علاقات (CRM خفيف)

استخدم بعد اجتماع/مکالمة/بريد عندما يقول المستخدم: «تابع مع…»، «ماذا وعدنا؟»، «CRM»، «follow-up»، أو إغلاق حلقة وعود.

**ليس** نظام CRM كامل — حلقة متابعة خفيفة داخل الغرفة.

## التصنيف
- **مستوى 1:** جهة خارجية / شريك / جهة مانحة / مجلس — متابعة كاملة + مسودة
- **مستوى 2:** تنسيق داخلي مهم — مهام + تذكير
- **مستوى 3:** روتين — سطر حالة فقط

## التدفق
1. اجمع الإشارات: ملاحظات المستخدم، `mail_search`/`gmail_read`، `room_calendar_list`، `room_memory_list`، `room_tasks_list`.
2. استخرج: **الوعد** · **المسؤول** · **الموعد** · **القناة** (بريد/تيليجرام/اجتماع).
3. أخرج جدول متابعة:
   | الجهة | الوعد | المسؤول | الاستحقاق | الحالة | الخطوة التالية |
4. صِغ مسودة متابعة واحدة واضحة لكل بند عالي الأولوية (وسمها «مسودة — لم تُرسل»).
5. اقترح `room_tasks_create` للوعود المملوكة — لا تنشئ دون موافقة إن كان المستخدم لم يطلب «أضف للمهام».
6. للتنبيه الجماعي المختصر: نص جاهز لـ `send_message` بعد موافقة.

## قواعد
- لا إرسال بريد/تيليجرام تلقائي.
- لا تخترع وعوداً أو مواعيد غير مذكورة — ضع «يحتاج تأكيداً».
- تجنّب «فقط أتحقق»؛ كل مسودة فيها طلب أو معلومة محددة.
