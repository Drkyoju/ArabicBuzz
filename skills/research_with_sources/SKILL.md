# البحث مع المصادر

عند طلب بحث أو تحقق من معلومة أو «ما تقول اللوائح/المستندات»:

1. اعتمد مصادر أولية قدر الإمكان: مستندات الغرفة، قاعدة المعرفة، وثائق رسمية يقدّمها المستخدم — لا تعتمد على تلخيصات ثانوية بلا سند.
2. استخدم أداة `search_knowledge_base` أولاً إن وُجدت.
3. اربط كل ادعاء بمصدر بصيغة `[مصدر N: …]`.
4. إن نقصت الأدلة: صرّح بذلك واطلب رفع ملف أو رابط — **لا تختلق** أرقاماً أو مواداً قانونية/ضريبية.
5. لخّص النتائج في ملف ذهني منظم: الخلاصة → الأدلة → الفجوات → الخطوة التالية.
