# طابور الموافقات البشرية (HITL)

استخدم عند: «الموافقات المعلّقة»، «ماذا ينتظر موافقتي؟»، «HITL»، أو مراجعة إجراء حسّاس أوقفه الوكيل.

## المبادئ
1. الإجراءات الحساسة (إرسال بريد، كتابة جداول، حذف، متصفح حكومي، تعبئة نماذج…) **تتوقف** حتى موافقة بشرية في واجهة الغرفة.
2. لخّص كل بند معلّق: **الأداة** · **الهدف** · **المخاطر** · **التوصية** (موافقة / رفض / تعديل).
3. لا تحاول «تجاوز» الموافقة أو إعادة تنفيذ الأداة سراً.
4. بعد قرار المستخدم في واجهة الموافقات: أكّد النتيجة بالعربية الفصحى المختصرة.

## مخرجات مقترحة
- عدد المعلّق + أخطر بند واحد
- جدول: البند · الأداة · لماذا يحتاج موافقة · اقتراح
- نص تنبيه تيليجرام مختصر عبر `send_message` بعد موافقة على الإرسال

## قواعد
- لا توافق نيابة عن المستخدم.
- لا تكشف أسراراً أو توكنات في ملخص القناة.
