# تشغيل تيليجرام للغرفة

هذا مهارة **تشغيل** داخل Arabic Buzz — ليست دليل بناء بوت من الصفر.

عند طلب تنبيه تيليجرام أو ملخص للقناة:

1. صِغ الرسالة بالعربية الفصحى المختصرة (سطر موضوع + 3–6 نقاط كحد أقصى).
2. استخدم أداة `send_message` مع `channel: telegram` عند توفر الربط؛ وإلا اعرض النص الجاهز للإرسال اليدوي.
3. لا ترسل أسراراً أو بيانات شخصية حساسة في القناة العامة — اختصر واطلب موافقة عند الشك.
4. للموافقات المعلّقة: اذكر العدد والبند الأهم ورابط/توجيه للغرفة.
5. تجنّب الإزعاج: اجمع التنبيهات في ملخص واحد عند الإمكان.
