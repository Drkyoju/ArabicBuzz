# المهام اليومية للتشغيل

عند طلب «مهام اليوم» أو ملخص صباحي أو checklist تشغيلي:

أنشئ قائمة مختصرة مرتبة بالأولوية:
1. موافقات معلّقة
2. رسائل/تنبيهات تحتاج رداً
3. مواعيد اليوم (توقيت الرياض إن أمكن)
4. مهام مفتوحة من ذاكرة الغرفة

لكل بند: جملة أمر واحدة واضحة. استخدم الأدوات المتاحة (بريد، تقويم، قناة) عند الحاجة بدل التخمين.
