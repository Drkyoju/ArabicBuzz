# مراجعة العقود (جمعيات / فصحى)

استخدم عند: «راجع العقد»، «عقد توريد»، «اتفاقية خدمة»، «عقد متطوع»، «عقد إيجار»، أو contract review.

## مبادئ
1. هذا **قائمة تحقق تشغيلية** وليست استشارة قانونية ملزِمة — أوصِ بمراجعة مختص عند المخاطر العالية.
2. لا تختلق بنوداً أو أرقاماً أو تواريخاً غير موجودة في النص.
3. اعمل بالعربية الفصحى المهنية؛ اترك الأرقام والتواريخ والرموز القانونية `dir`-محايدة.

## المخرجات (دائماً)
1. **ملخص العقد** (طرفان، موضوع، مدة، قيمة إن وُجدت)
2. **بنود مكتملة** — ما يظهر صراحة
3. **نواقص شائعة** — جدول: البند · لماذا يهم · سؤال للمستخدم
4. **مخاطر محتملة** — صياغة / غموض / التزامات مفتوحة / إنهاء / سرية / نزاع
5. **أسئلة قبل التوقيع** (3–7)
6. **اقتراح تعديلات لغوية** فقط إن طُلب — لا تغيّر الملف دون موافقة

## قائمة تحقق سريعة (جمعيات)
- أطراف واضحة + صفة التوقيع
- نطاق العمل / التسليمات
- المدة والتجديد والإنهاء
- المقابل المالي وجدول الدفع (إن وُجد)
- السرية وحماية البيانات الشخصية
- المسؤولية والتعويض (إن ذُكر)
- القانون الواجب / جهة النزاع (لا تخترع نصاً نظامياً)
- مرفقات وملاحق مشار إليها فعلاً في المتن

## التدفق
1. افتح المستند من الغرفة/المعرفة إن وُجد (`brain_open_document` / بحث).
2. راجع النص فقط — لا تفترض «عرف السوق» كحقيقة.
3. إن نقصت صفحة أو ملحق: سجّل تحت «نواقص».
4. للتعديل: اقترح صياغة ثم نفّذ بـ `edit_document` بعد موافقة صريحة.
