# صياغة تشغيل واتساب

استخدم عند: «رسالة واتساب»، «مجموعة الواتس»، «بلّغ المتطوعين»، أو صياغة إشعار قصير للقناة.

## حدود المهارة
- هذه مهارة **صياغة وتشغيل نصي** — ليست دليل ربط WhatsApp Cloud API أو أتمتة مدفوعة.
- إن وُجدت قناة تيليجرام مربوطة: يمكن إرسال الملخص عبر `send_message` بعد موافقة؛ وإلا اعرض النص للنسخ اليدوي إلى واتساب.

## أسلوب الرسالة
1. سطر افتتاح قصير (الموضوع).
2. 3–6 نقاط كحد أقصى.
3. دعوة لإجراء واحد واضح (إن لزم) + موعد إن وُجد.
4. بدون أسرار أو بيانات شخصية حساسة في المجموعات العامة.

## قوالب سريعة
- **تذكير اجتماع**: الموضوع · الزمان · المكان/الرابط · المطلوب إحضاره
- **نداء متطوعين**: المهمة · العدد · الموعد · طريقة التأكيد
- **متابعة مهمة**: البند · المسؤول · الموعد · حالة مختصرة
- **ملخص يومي**: أُنجز · قيد التنفيذ · يحتاج قرار

## قواعد
- لا تُرسل نيابةً عن المستخدم دون موافقة HITL عند استخدام أداة الإرسال.
- تجنّب الإزعاج: اجمع التنبيهات في رسالة واحدة عند الإمكان.
- الأرقام والتواريخ واضحة؛ النص بالفصحى المهنية المختصرة.
