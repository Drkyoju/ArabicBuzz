# بنّاء العروض العربية

استخدم عند: «عرض تقديمي»، «شرائح»، «PPT»، «presentation»، أو تحضير عرض لمجلس/شركاء.

## الهيكل الافتراضي
1. شريحة عنوان (الجمعية · الموضوع · التاريخ)
2. الهدف / الأجندة
3. المحتوى (شريحة واحدة لفكرة واحدة)
4. قرارات مطلوبة أو توصيات
5. خاتمة / خطوات تالية

## مبادئ RTL
- محاذاة يمين للنص العربي؛ الروابط والأرقام اللاتينية الطويلة في سياق LTR واضح.
- عناوين قصيرة؛ نقاط لا تزيد عن 5 لكل شريحة.
- لا تملأ الشريحة بفقرات — انقل التفصيل لمذكرة مرافقة إن لزم.

## التنفيذ
- إن وُجد ملف PPTX/DOCX: عدّل بـ `edit_document` / اقرأ ثم اقترح نص الشرائح.
- وإلا: أخرج نص الشرائح جاهزاً للنسخ (عنوان + نقاط) بالعربية الفصحى، أو أنشئ مستنداً عبر الأدوات المتاحة.
- لا تختلق إحصاءات أو نسب إنجاز غير مذكورة في المصادر.
