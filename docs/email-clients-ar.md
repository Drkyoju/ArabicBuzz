# بريد Arabic Buzz — الشخصي والجمعية

## نافذتان منفصلتان

| | **بريدي الشخصي** | **بريد الجمعية** |
|--|--|--|
| المسار | `/?section=personal-mail` | `/?section=mail` |
| المصدر | Gmail API لحساب Google المربوط للمستخدم | IMAP/SMTP لـ `info@alhuda-alhikma.sa` (أو ما يضبطه المالك) |
| الخصوصية | بريد المستخدم فقط — لا يُشارك مع موظفين آخرين | صندوق الجمعية المشترك لأعضاء الجلسة |
| الربط | زر «اربط بريدي في Google» (OAuth) | إعدادات IMAP للمالك مرة واحدة |

في واجهة الموظف يظهر الاسمان بوضوح في الشريط الجانبي: **بريدي الشخصي** و**بريد الجمعية** — لا تخلط بينهما.

## ما يفعله الذكاء (عملي)

- بحث في كل البريد + المرفقات
- تلخيص الرسالة + تصنيف سريع (شخصي: عاجل / إجراء / اطلاع / ضوضاء)
- مسودة رد → مراجعة في الصندوق → إرسال أو «أرسل فوراً»
- وكلاء الغرفة: `gmail_*` = الشخصي فقط · `mail_*` = الجمعية فقط (لا خلط)

## متوفر الآن (عميل البريد)

| الميزة | الحالة |
|--|--|
| تنزيل المرفقات داخل الواجهة | متوفر |
| تأجيل (Snooze) | متوفر — يعتمد على cron لإيقاظ الرسالة |
| جدولة الإرسال | متوفر — يعتمد على cron للإرسال في الموعد |
| تذكيرات على رسالة | متوفر — يعتمد على cron للتنبيه |
| إشعار المتصفح للبريد الشخصي (غير مقروء) | متوفر عبر استطلاع خفيف |
| صندوق كامل، مجلدات، بحث، ملخص، مسودة، إرسال | متوفر |

### اعتماد الـ Cron

ميزات **الاستيقاظ من التأجيل** و**جدولة الإرسال** و**التذكيرات** تُعالَج عبر مسار الـ cron (`/api/crons/runner` → mail energy). بدون تشغيل الـ cron في الموعد لن تُنفَّذ هذه المهام في الخلفية — راجع `docs/cranl-deploy.md` وGitHub Actions للـ cron.

## صلاحيات Google المطلوبة (Consent)

بعد تسجيل الدخول بالهوية فقط، الربط يطلب:

- `gmail.readonly` — قراءة وبحث
- `gmail.send` — إرسال/رد
- `gmail.modify` — مقروء/غير مقروء + نجمة + تأجيل عبر التسميات

من سبق وربط قبل `gmail.modify` يجب **إعادة الموافقة** من «أعد الربط».

### Google Cloud Console (يدوياً)

1. فعّل **Gmail API** في المشروع
2. OAuth consent: أضف النطاقات أعلاه (حساسة — تحذير «تطبيق غير موثّق» طبيعي حتى Verification)
3. إن بقي التطبيق في **Testing**: أضف كل مستخدم كـ Test user
4. راجع `docs/google-oauth-ar.md`

الكود جاهز؛ إن رُفضت الصلاحية من Google تظهر رسالة `needsReconsent` في الواجهة.

## وكلاء / أدوات

- لا تستخدم `gmail_search` لصندوق الجمعية — استخدم `mail_search`
- قبل الإصلاح كانت أدوات gmail_* تسقط على IMAP عند توفره؛ أُصلح ذلك
