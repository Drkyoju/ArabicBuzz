# Telegram Local Bot API (اختياري — ملفات أكبر من 20 م.ب)

بوتات تيليجرام السحابية لا تستطيع تنزيل ملفات أكبر من **~20 م.ب**.

## المسارات المجانية المفضّلة (ArabicBuzz)

1. ضغط PDF ثم إعادة إرساله في «عمل الجمعية» مع تعليق الطلب.
2. رفع الملف من الموقع → ملفات الغرفة.
3. رفع الملف إلى عقل الشركة (Drive) **بنفس الاسم الحرفي** ثم ذكره في المجموعة.

## Local Bot API Server

- https://github.com/tdlib/telegram-bot-api
- يحتاج `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` من https://my.telegram.org

حد الرفع السحابي لـ `sendDocument` ≈ 50 م.ب.
