| | |
|---|---|

| --- | --- |
| طلب («أبغى كذا» / صوت عملي / ملف مع تعليق) | تنفيذ فوري + رد بالناتج **بدون منشن** |
| دردشة بشرية / تحية / تفاعل | صامت (الوسائط تُؤرشف فقط) |

وضع المجموعة: `intent_execute_reply_casual_silent`

## أرشيف الملفات والصوت → الغرفة / Drive

| النوع | المسار |
| --- | --- |
| مستند / صورة / فيديو | تنزيل متسلسل (سحابة → Local Bot API → جسر الماك) → خزنة الغرفة → مرآة `telegram_attachments` → مزامنة Drive أفضل-جهد |
| صوت / ملاحظة صوتية | أرشفة الـ `.ogg` **قبل** التفريغ (STT) → sidecar تفريغ `.txt` عند النجاح → Drive أفضل-جهد |
| دردشة بشرية بدون طلب | صامت في الشات — الوسائط تُؤرشف فقط |
| فشل STT | الصوت يبقى في أرشيف الغرفة؛ رسالة خطأ عربية للمستخدم |

الأسماء الصوتية: `tg-voice-{YYYYMMDDHHmm}-{chat}-{from}.ogg` لتسهيل البحث في Drive.  
المزامنة مع عقل الشركة تحتاج Google OAuth للمالك مرة واحدة من الموقع. عطّل الاستيراد بـ `TELEGRAM_MEDIA_IMPORT=0` أو إعداد الغرفة.

| خطابات | `list_letter_templates` · `letter_fill_template` |
| محضر | `minutes_from_thread` |

## حدود صادقة

- Drive يحتاج ربط Google من الموقع مرة واحدة.
- مشاركة ACL على Drive غير متاحة من البوت (صلاحيات OAuth) — رابط العرض فقط.
- خاص فقط لمن ضغط Start؛ وإلا منشور في المجموعة.
- حذف ملفات الغرفة/Drive بموافقة بشرية.
- PDF عربي: `pdf_replace_text` أدق؛ إعادة البناء محدودة.
