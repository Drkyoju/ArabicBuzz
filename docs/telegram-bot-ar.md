# بوت تيليجرام @alhuda14bot — الموقع في الجيب

الموقع الحي: https://arabicbuzz-fooc9h.cranl.net/  
البوت: https://t.me/alhuda14bot

## الجواب الصادق

**نعم جزئياً.** البوت يشغّل نفس أدوات غرفة الموقع على طلبات العمل (بحث · ملفات · بريد · تقويم · مهام · تحويل · OCR…) ويرسل النتائج/الملفات هنا.  
**ليس** نسخة بصرية كاملة: لا سبورة tldraw، ولا شريط TipTap، ولا أداة رسم PDF بالقلم — لكن المكافئ عبر أدوات (تعليق محروق، مسودة بريد، تعديل مستند).

## السياسة (مهم)

**المنشن اختياري.** القصد يحدد السلوك:

| الرسالة | السلوك |
| --- | --- |
| طلب («أبغى كذا» / وين الملف / صوت عملي / ملف مع تعليق) | تنفيذ فوري + رد بالناتج **بدون منشن** |
| دردشة بشرية / تحية / تفاعل | صامت (الوسائط تُؤرشف فقط) |
| خاص (DM) | دائماً يساعد على الطلبات |
| حذف رسائل تيليجرام | ممنوع نهائياً |

وضع المجموعة: `intent_execute_reply_casual_silent`

## ماذا يعمل من تيليجرام (نهاية لنهاية)

| القدرة | أمثلة / أدوات |
| --- | --- |
| بحث موحّد | «ابحث في الغرفة عن …» → `room_search` (بريد جمعية · ملفات · تقويم) |
| إحاطة الصباح | «إحاطة الصباح» / «ملخص اليوم» → `owner_morning_brief` |
| تقويم الغرفة | «احجز موعد غداً ١٠ص» → `room_calendar_*` |
| مهام | «أضف مهمة متابعة التقرير» → `room_tasks_*` |
| ملفات / Drive | «جيب اللائحة» · عدّل · حوّل · OCR · `return_file` |
| تعليق PDF | `pdf_annotate` / `pdf_stamp` / `pdf_replace_text` ثم مرفق |
| بريد الجمعية | `mail_*` (أعضاء الجلسة) |
| Gmail شخصي | `gmail_*` إن رُبط Google لهوية مالك القناة |
| تبليغ | «أرسل لأحمد: …» → `notify_room_member` |
| بحث ويب | `web_search` / `web_fetch` |
| صوت | تفريغ → قصد → تنفيذ فوري إن كان طلباً |

## ماذا يبقى موقع فقط (واجهة)

- لوحة PDF Expert / رسم حر بالقلم على الصفحة
- محرر TipTap البصري وشريط التنسيق
- سبورة tldraw / مخططات تفاعلية
- إعدادات الحساب وربط Google OAuth (يُربَط من الموقع ثم يستفيد البوت)
- تجربة لوحة اليوم الرسومية (البطاقة) — المحتوى نفسه عبر `owner_morning_brief`

## حدود صادقة

- Drive يحتاج ربط Google من الموقع.
- خاص فقط لمن ضغط Start؛ وإلا منشور في المجموعة.
- حذف ملفات الغرفة/Drive بموافقة بشرية.
- PDF عربي: `pdf_replace_text` أدق؛ إعادة البناء محدودة.

## للمطوّرين

- `resolveGroupReplyMode({ workKind })` — intent gate
- `lib/telegram/attachment-deliver.ts` — تسليم الملفات
- `lib/telegram/never-delete.ts` — حظر حذف تيليجرام
- `room_search` · `owner_morning_brief` · `pdf_annotate` — أدوات جيب الموقع
