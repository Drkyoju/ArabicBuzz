الموقع الحي: https://arabicbuzz-fooc9h.cranl.net/  
البوت: https://t.me/alhuda14bot

## ماذا يفعل؟

القروب/الخاص المربوط = **غرفة الفريق على الموقع** بنفس الوكلاء والأدوات:

| القدرة | أمثلة عربية |
| --- | --- |
| تقويم الغرفة | «احجز موعد غداً ١٠ص» · «كم موعد اليوم؟» |
| مهام | «أضف مهمة متابعة التقرير» |
| ملفات / Drive | «جيب اللائحة» · «عدّل الملف» · «حوّل إلى Word» · «زامن الدرايف» |
| بريد الجمعية | «ابحث في البريد عن …» · «أرسل إيميل إلى …» |
| بحث ويب | «ابحث عن …» |
| تبليغ أعضاء | «أرسل لأحمد: …» · «بلّغ المجموعة: …» |
| إيقاظ وكلاء | «يا وكيل١ لخّص» · «أيقظ الوكيل» |
| صوت | رسالة صوتية → تفريغ → **تنفيذ فوري** |
| OCR | صورة أو PDF ممسوح |

## سياسة الرد

| السياق | السلوك |
| --- | --- |
| **خاص (DM)** | تنفيذ كامل + رد حر |
| **مجموعة بدون منشن** | تنفيذ صامت + إرسال الملفات/أزرار الموافقة عند الطلب |
| **منشن / رد على البوت** | رد نصي كامل |
| **ما عرفت / ما حصلت** | جملة قصيرة ظاهرة |
| **حذف رسائل تيليجرام** | ممنوع نهائياً |

## حدود صادقة

- **Drive** يحتاج ربط Google من الموقع.
- رسالة **خاصة** فقط لمن ضغط Start؛ وإلا منشور في المجموعة.
- **حذف ملفات** الغرفة/Drive بموافقة بشرية فقط.
- **PDF عربي:** `pdf_replace_text` (HarfBuzz) أدق؛ إعادة البناء عبر pdf-lib محدودة لاتصال الحروف.
- إعداد IMAP لبريد الجمعية للمالك؛ الاستخدام متاح للأعضاء المسجّلين.

## للمطوّرين

- Webhook: `POST /api/webhooks/telegram` · صحة: `GET` نفس المسار
- تسليم الملفات في الوضع الصامت: `lib/telegram/attachment-deliver.ts`
- حظر الحذف: `lib/telegram/never-delete.ts`
- أدوات كاملة على كل دور غير «تحية»: `fullRoom` في `lib/telegram/bot.ts`
