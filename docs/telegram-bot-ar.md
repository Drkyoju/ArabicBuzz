## ماذا يفعل؟

القروب المربوط = **غرفة الفريق على الموقع** بنفس الوكلاء والأدوات:

| القدرة | أمثلة عربية |
| --- | --- |
| تقويم الغرفة | «احجز موعد غداً ١٠ص» · «كم موعد اليوم؟» |
| مهام | «أضف مهمة متابعة التقرير» |
| ملفات / Drive | «حوّل الملف إلى Word» · «ابحث عن اللائحة» · «زامن الدرايف» |
| بريد الجمعية | «ابحث في البريد عن …» · «أرسل إيميل إلى …» (للأعضاء المسجّلين) |
| Gmail الشخصي | إن رُبط Google من الموقع |
| تبليغ أعضاء | «أرسل لأحمد: …» · «بلّغ المجموعة: …» · «نسّق مع سارة: …» |
| إيقاظ وكلاء | «يا وكيل١ لخّص» · «أيقظ الوكيل» · «أبغا للجميع …» |
| صوت | سجّل رسالة صوتية → تفريغ → أزرار + تنفيذ تلقائي |
| OCR | أرسل صورة أو PDF ممسوح |

## كيف تستخدمه؟

1. أضف `@alhuda14bot` مشرفاً في المجموعة (رسائل + وسائط).
2. `/link` (أو `/link@alhuda14bot`).
3. BotFather → **Group Privacy → Disable** ليرى الرسائل العادية بلا منشن.
4. اكتب بالعربية العادية — **بدون `/ask`**.

أوامر مفيدة: `/help` · `/status` · `/rooms` · `/approve` · `/ping`

## حدود صادقة

- **Drive** يحتاج ربط Google من الموقع.
- رسالة **خاصة** فقط لمن ضغط Start على البوت سابقاً؛ وإلا منشور في المجموعة.
- **حذف ملفات** الغرفة/Drive بموافقة بشرية فقط.
- البوت **لا يحذف أي رسالة على تيليجرام** أبداً (يعدّل رسالة التقدّم أو يتركها ويرد جديداً).
- إعداد IMAP لبريد الجمعية للمالك؛ **الاستخدام** متاح للأعضاء المسجّلين.
