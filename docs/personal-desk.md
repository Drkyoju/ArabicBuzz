# المساحة الشخصية مقابل بريد الجمعية

## ما هي «مساحتي الشخصية»؟

مساحة عمل **خاصة بكل موظف** (`personal-u-{userId}`):

- الرسائل والملفات وتشغيل الوكلاء والمسودات والذاكرة **لا تظهر** لغرفة الفريق ولا لزملاء آخرين.
- صلاحيات الوكلاء كاملة (نفس مقاعد/نماذج الفريق)، لكن السجل يبقى خاصاً.
- لا دعوات أعضاء ولا مشاركة تلقائية مع عقل الشركة (Drive).

غرفة الفريق (`shared-demo`) تبقى الغرفة المشتركة الوحيدة للعمل الجماعي.

## البريد: شخصي ≠ جمعية

| | بريد الجمعية | البريد الشخصي |
|--|-------------|---------------|
| أين؟ | الإعدادات → بريد الجمعية / IMAP | مساحتي الشخصية → «بريدي الشخصي» |
| لمن؟ | صندوق المؤسسة (`info@…`) | حساب Google/Gmail للموظف |
| من يراه؟ | حسب صلاحيات التشغيل | صاحب المساحة فقط |
| الاستخدام | عمليات الجمعية | واردك + مساعدة مسودة رد (دون إرسال تلقائي) |

ربط Google من المساحة الشخصية يستخدم نفس OAuth للمستخدم، لكنه **لا ينقل** محتوى بريدك إلى غرفة الفريق تلقائياً. لا تستخدم أدوات البريد الشخصية داخل غرفة الفريق إن كنت لا تريد مشاركة الملخصات هناك.
