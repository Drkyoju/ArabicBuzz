# الصوت ووكلاء غرفة الفريق

## كيف يشتغل (سطر واحد)

**كل رسالة في الغرفة المشتركة يطّلع عليها وكيل شغال فوراً — بلا @؛ والطلب («أبغا…») يُنفَّذ، والدردشة برد قصير.**

## الصوت

1. اضغط الميكروفون في الغرفة أو «ملفات الفريق».
2. التسجيل يمرّ بتنظيف محلي خفيف (high-pass) ثم نسخ عربي (Willow → Gemini → HF → Groq Whisper).
3. **راجع النص وعدّله** قبل الإرسال/الحفظ — لا تُرسل طلاسم.
4. أمثلة صوتية:
   - «أبغا اللائحة»
   - «أبغا الملف كذا»
   - «عدّل …»
   - «يا وكيل١ لخّص»
   - «أبغا للجميع …» / «للوكلاء: …»

## الوكلاء

- الغرفة المشتركة: حضور ٢٤ ساعة — لا ينطفئون وحدهم.
- اضغط مقعد الوكيل: **شغال ↔ طافي**. الطافي لا يراقب ولا يرد.
- الافتراضي: شغال.
- بدون @mention: مراقب واحد (المكتب أو أول جاهز) لكل رسالة — تفادي إزعاج ٤٠ وكيلاً.
- `@الجميع` أو «أبغا للجميع» يشغّل الجاهزين معاً (بحد أقصى).

## حدود صادقة

- جودة النسخ تعتمد على الميكروفون والشبكة ومفتاح Gemini/Groq/Willow المتاح.
- راجع النص دائماً قبل الإرسال.
- المساحة الشخصية لا تفرض مراقب تلقائي بنفس صرامة الغرفة المشتركة.
