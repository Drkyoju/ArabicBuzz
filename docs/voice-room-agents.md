# الصوت ووكلاء غرفة الفريق

## كيف يشتغل (سطر واحد)

**تكلم → النص يظهر حياً في المربع → أوقف → راجع النسخ العربي → Enter للإرسال (لا تلقائي).**

## الصوت

1. اضغط الميكروفون في غرفة الفريق أو مساحتي الشخصية أو مهام التشغيل أو «ملفات الفريق».
2. أثناء الحديث يُكتب الكلام مباشرة في مربع النص (مسودة حية).
3. بعد الإيقاف يُنقّح النص عربياً في **نفس المربع** (Willow → Gemini → HF → Groq Whisper).
4. **راجع وعدّل ثم أرسل يدوياً** (Enter في الغرفة / زر إرسال أو ⌘Enter في المساعدين) — لا إرسال تلقائي.
5. أمثلة صوتية:
   - «أبغا اللائحة»
   - «أبغا الملف كذا»
   - «عدّل …»
   - «يا وكيل١ لخّص»
   - «أبغا للجميع …» / «للوكلاء: …»

## الوكلاء

- الغرفة المشتركة: الرسالة توقظ وكيلاً جاهزاً.
- اضغط مقعد الوكيل: **شغال ↔ نائم**.
- `@الجميع` أو «أبغا للجميع» يشغّل الجاهزين معاً (بحد أقصى).

## حدود صادقة

- جودة النسخ تعتمد على الميكروفون والشبكة ومفتاح Gemini/Groq/Willow المتاح.
- المسودة الحية قد تكون تقريبية — راجع دائماً قبل Enter.
